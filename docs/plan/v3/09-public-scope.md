# 공개 범위 판단

결론: 대부분의 엔진 모듈은 오픈 소스 공개가 가능하지만, 브라우저 제어 라이브러리와 사내 대시보드 컴포넌트는 법무 보안 검토와 라이선스 확인이 필요하다. 개인 경로와 비밀은 소스코드 밖으로 분리한다.

## 이식 및 재작성 후보 공개 여부

| 기능 | 공개 가능 여부 | 라이선스 (서드파티) | 내부 정보 포함 |
|---|---|---|---|
| internal/api | 가능 | 없음 | 없음 |
| internal/automation | 가능 | 없음 | 없음 |
| internal/browser | 이사 결정 필요 | 확인 필요 (CDP 라이브러리) | 없음 |
| internal/config | 가능 (비밀 배제 시) | 없음 | 없음 |
| internal/policy | 가능 | 없음 | 없음 |
| internal/schedule | 가능 | 없음 | 없음 |
| internal/store | 가능 (비밀 배제 시) | 없음 | 없음 |
| web/ | 이사 결정 필요 | 확인 필요 (UI 컴포넌트) | 확인 필요 (라우트 규칙) |
| migrations/ | 가능 | 없음 | 확인 필요 (더미 데이터) |

## 이사 결정 필요 목록
- **브라우저 CDP 통신부**: 상용 웹 서비스 자동화 우회 등 서드파티 약관 위배 가능성이 있으므로 법무팀 검토 후 공개 범위를 확정한다.
- **웹 대시보드 컴포넌트**: 기존 조직 내부망에 맞춰 하드코딩된 API 엔드포인트나 사내 결재 라우팅 코드가 있다면, 오픈 소스용으로 범용화해야 한다.

## 삭제할 개인 경로 및 비밀 목록
문서 및 이식 대상 코드에 포함되지 않도록 아래 값의 물리적 위치와 주입 방식을 환경 변수로 대체한다.
- **DB 볼륨 마운트 절대 경로**: .env의 WB_PROJECTS_ROOT 등 사용자 홈에 종속된 경로는 코드에서 배제한다.
- **API 토큰 및 DB 비밀번호**: .env 혹은 Docker Compose 파일에 위치한 시크릿 값은 문서화하지 않고 실행 환경 주입 템플릿만 제공한다.
