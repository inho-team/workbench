# 목표 구조

이 문서는 엔진(oh-my-teams)과 제품(workbench)의 분리를 전제로 목표 아키텍처를 확정한다. 제품의 호스트 서비스 언어, 상태 저장소, 계정 격리 실행기, 화면 및 권한 구조를 효율 관점에서 비교하여 결정한다. 또한, 구형 설계 초안인 8028b89의 자산을 선별 수용하여 시스템의 안정성과 확장성을 동시에 확보한다.

## 엔진과 제품 경계

사용자의 "엔진과 제품 분리" 확정에 따라 역할을 나눈다. 엔진(oh-my-teams)은 역할, 워크플로, 비동기 신호 등 다중 에이전트 조율 로직을 순수 런타임 스크립트로 제공한다. 제품(workbench)은 엔진을 내장하고 데이터베이스, 컨테이너 계정 격리, 브라우저 제어, 데스크톱 및 웹 화면을 통합하는 애플리케이션이다.

## 비교 및 결정표

### 호스트 서비스 언어

| 대안 | 유휴 메모리 | 시작 시간 | 동시 에이전트 비용 | 배포 크기 | OMT 결합 비용 |
|---|---|---|---|---|---|
| Node.js | 보통 | 보통 | 높음 (V8 인스턴스 중복) | 큼 | 매우 낮음 |
| **Go (결정)** | **매우 낮음** | **매우 빠름** | 낮음 (고루틴) | **작음** (단일 바이너리) | 높음 (IPC 필요) |

- **결정 이유**: [재고 01 문서](01-legacy-inventory.md)에 실측된 8.9MB 단일 정적 바이너리와 낮은 유휴 비용이 OMT 결합 오버헤드를 넘어선다.
- **효율 근거**: Node.js 인스턴스 당 기본 50MB 이상을 점유하는 데 반해, Go는 극소 메모리로 동작한다(미측정, 측정 계획: 두 바이너리 빈 런타임 메모리 비교).

### 상태 저장소

| 대안 | 동시성 | 백업 | 설치 부담 | 메모리 오버헤드 |
|---|---|---|---|---|
| 파일 시스템 | 낮음 | 단순 | 없음 | 낮음 |
| **SQLite (결정)** | 보통 | 단순 (단일 파일 복사) | 없음 (내장) | 낮음 |
| PostgreSQL | 매우 높음 | 복잡 | 매우 높음 | 높음 (데몬 상주) |

- **결정 이유**: 워크스테이션에서 외부 DB 프로세스의 상주 메모리(100MB+)는 에이전트 구동을 방해하므로 배제한다.
- **효율 근거**: PostgreSQL 설치 시 백그라운드 메모리 오버헤드가 크지만, SQLite는 애플리케이션 내장으로 유휴 비용이 0이다(미측정).

### 계정 격리 실행기

| 대안 | 효율 (메모리/속도) | 계정 격리 강도 | 실측/근거 |
|---|---|---|---|
| Docker Desktop | 낮음 (무거운 VM 1~2GB) | 높음 | legacy M-14 (`legacy-workbench/docs/16-구독-설계.md:326-365`) |
| **가벼운 런타임 (결정)** | 높음 (가벼운 VM 또는 루트리스) | 높음 | 초안 8028b89 `docs/account-isolation.md` |

- **결정 이유**: 다중 계정을 위해 컨테이너 격리를 쓰되, OS별 최적의 경량 런타임(macOS는 OrbStack/Colima, Linux는 Podman, Windows는 WSL2 직접 배포판)을 선택한다.
- **효율 근거**: OrbStack은 Docker Desktop 대비 RAM 1/5, 유휴 CPU 0%를 기록했다(legacy M-14 측정값).

### 화면 (구조 확정 사항)

사용자가 확정한 조합을 토대로 다음 구조를 사용한다.
- **데스크톱**: Tauri 기반 네이티브 데스크톱 앱.
- **모바일**: Capacitor를 이용한 JS 번들 OTA 핫 업데이트.
- **원격 연결**: Tailscale VPN과 보안 토큰을 결합해 사설망 안에서만 접근을 허용한다.

### 도구 권한 강제와 OMT 역할 결합

- **결정**: legacy의 도구 화이트리스트 셸 브리지 엔진을 OMT 직무 역할 명세와 연동한다.
- **이유**: [재고 01 문서](01-legacy-inventory.md)의 `entrypoint.sh` 관문 실측(`legacy-workbench/deploy/agy/entrypoint.sh:1-35`)에서 증명된 차단 방식을 OMT의 `permissions.allow` 배열에 병합하여, 역할에 허락되지 않은 도구 호출을 OS 수준에서 원천 차단한다.

## 초안 (8028b89) 반영 내역

- **채택**: OS별(macOS/Linux/Windows) 경량 컨테이너 조합 분기 설계. 출처: `초안 8028b89 docs/account-isolation.md`.
- **채택**: 다중 계정 약관 위반 방지를 위한 기본 비활성화 방침 및 Tailscale 사설망 기반 원격 접속 보안, Capacitor OTA 정책. 출처: `초안 8028b89 docs/risks.md`.
- **미채택**: `decisions/0001-engine-product-separation.md`와 `0002-host-service-language.md`. 이유: 저장소 커밋에 파일이 존재하지 않아 확인할 수 없었다.
