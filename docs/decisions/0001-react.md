# React

결론: 화면 구성 기술로 React를 사용한다.

## 맥락

omt-console은 데스크톱과 모바일 앱에서 동일한 대화형 화면을 제공해야 한다. 이를 위한 UI 라이브러리를 선택해야 한다.

## 대안

- React
- Vue, Svelte 등 다른 프론트엔드 프레임워크

## 결정

React를 화면 구성 기술로 결정한다. 이 조합은 사용자가 확정했다.

## 결과 및 감수하는 위험

- 데스크톱(Tauri)과 모바일(Capacitor)에서 같은 React 컴포넌트를 공유하여 개발 생산성을 높일 수 있다.
- React 생태계의 풍부한 라이브러리를 활용할 수 있다.
