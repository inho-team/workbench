# Tailscale과 토큰 인증

결론: 모바일 클라이언트에서 데스크톱 본체로 원격 접속할 때 Tailscale 네트워크와 토큰 인증을 사용한다.

## 맥락

모바일 앱이 데스크톱 본체의 OMT 런타임 및 상태 정보에 접근해야 하므로, 안전하고 설정이 쉬운 원격 접속 수단이 필요하다. 기존 OMT 대시보드(참고: `oh-my-teams/docs/plan/headless-runtime.md`의 대시보드 절)와 일관된 방식을 유지해야 한다.

## 대안

- Tailscale + 토큰 인증 (선택)
- 포트 포워딩과 자체 TLS + 인증
- 외부 릴레이 서버 사용

## 결정

기존 OMT 대시보드와 동일한 Tailscale 및 토큰 인증 방식을 선택한다. 이 조합은 사용자가 확정했다.

## 결과 및 감수하는 위험

- **접근성:** 별도의 방화벽 설정이나 포트 포워딩 없이 모바일 기기에서 데스크톱에 안전하게 접속할 수 있다.
- **보안 위험:** 모바일 기기 분실 시 토큰이 유출될 수 있으므로 권한 범위를 제한하고 토큰을 안전하게 저장해야 한다.
